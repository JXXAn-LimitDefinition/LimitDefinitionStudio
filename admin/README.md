# 极限定义工作室 · 本地编辑器使用说明（零基础版）

这是一个**只在你自己电脑上**打开的小工具，用来改官网的文字、颜色、作品和公告，改完一点就更新到网上。

## 你要做的（就三步）

1. **双击 `编辑网站.bat`**（就在网站文件根目录）。
   - 电脑会自动打开一个浏览器页面，网址 `http://127.0.0.1:3130`。
   - 记住：这个地址只有你的电脑打得开，别人上不了。
2. **在页面上改东西**：左边是表单，右边是实时预览，改一个字段，右边立刻能看到效果。
3. **发布**：
   - 点 **「保存」**：只改本地 + 刷新预览，**不会**发到网上。
   - 确认满意后，点 **「发布上线」**：自动构建并在 GitHub 上重新部署你的官网。

> 使用完直接关掉那个黑色命令行小窗口即可（那代表编辑器已退出）。

---

## 各个标签页能改什么

- **内容**：首页首屏、板块标题、定位、关于我们、能力、历程、团队成员、联系方式、页脚……所有文字。
- **主题**：
  - 一键切换预设配色（红线黑 / 青辉深蓝 / 血橙 / 银霜深灰）。
  - 「高级」里可单独改各个颜色和字号（更灵活，手动改）。
- **作品**：新增 / 编辑 / 删除作品；可以勾选「草稿」，草稿作品不会出现在线上。
- **动态**：新增 / 编辑 / 删除公告与开发日志；同样的草稿功能。
- **设置**：上传替换 Logo、查看历史版本并一键回滚、打开预览。

## 常见问题

**Q：双击后提示找不到 Node.js？**
A：去 https://nodejs.org/zh-cn 下载安装（一路点下一步），装好后再双击 `编辑网站.bat`。

**Q：点了「发布上线」报错？**
A：最常见是还没有登录 GitHub，或电脑上没装 git / pnpm。把报错信息发给技术人员，或按里面给的手动命令操作。

**Q：怎么把它设密码，防止同在电脑上的人乱改？**
A：在 `admin` 文件夹里新建一个叫 `.env` 的文件，里面写一行：
`ADMIN_PIN=你的密码`
然后重启编辑器，以后再打开就要先输入这个密码。（不是必须，因为默认只有本机才能访问。）

**Q：改坏了想退回上一版？**
A：到「设置」标签页 →「历史版本」，点某条记录右边的「回滚到此」即可。

## 给技术人员的一句话

- 服务器：`admin/server.mjs`（Node 标准库实现，零第三方依赖）。
- 前端：`admin/index.html` + `app.js` + `app.css`。
- 只监听 `127.0.0.1:3130`；写文件命中白名单（site.json / theme.json / content/**.md / public/logo.jpg / admin/publish-log.json）。
- 内容以 `src/data/site.json`（站点文字）、`src/data/theme.json`（主题令牌）、`src/content/works|news/*.md`（作品/公告，frontmatter 以 JSON 即合法 YAML 存储）为准。
- 发布 = `astro build` + `git commit/tag/push`；回滚 = 存档当前 → checkout 指定 tag → 重新构建推送。
